# Three-minute demo

Use fictional examples only. Start the app before the interview and make one warm-up call.

1. **0:00–0:30 — Input.** Select “Delayed Transfer”, show the short transcript, and create
   a handover. Explain that one local model call requests a specific JSON schema.
2. **0:30–1:20 — Evidence.** Inspect the amount and transfer reference. Click their Inspect
   buttons and compare the highlighted source lines. Point out completed checks separately
   from the proposed payments-team investigation. The delay reason should remain unknown.
   If it does not, show the failure honestly; do not present the output as verified truth.
3. **1:20–2:00 — Missing information.** Start a new conversation with “Incomplete
   Conversation”. Show that absent names, amounts and references can remain unknown.
   Explain that uncertainty should not be filled with plausible invented facts.
4. **2:00–2:30 — Workflow.** Edit the Markdown handover, save it, reopen it from history,
   and export it. Explain the distinction between the generated summary and the edited draft.
5. **2:30–3:00 — Evidence of engineering.** Open the dated evaluation report. Explain one
   actual failure, show latency/token measurements, and describe what citation validation
   can and cannot check. Optionally delete the demo record.

Backup: `scripts/record_demo.py` creates a terminal recording from real API responses.
Keep the recording and latest report available if the live model is slow.
