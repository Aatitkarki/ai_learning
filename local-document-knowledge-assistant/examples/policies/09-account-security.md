# Account security

DEMONSTRATION DATA — fictional policies for software experiments only.

## Suspicious activity

If a customer reports an unrecognized transfer, support must advise them to lock the account in the app and escalate to the fraud team. Support must never ask for a password, full card number, or one-time passcode.

## Account access

Password resets use the verified email address. A lost-phone report requires identity review before a phone-number change. Support cannot remove account controls through chat.
